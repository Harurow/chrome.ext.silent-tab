# Chrome拡張機能「静寂（Silent Tab）」

![静寂ロゴ](src/images/muted128.png)

## 概要

「静寂（Silent Tab）」は、新しいタブを開く際に自動的にミュート状態で開くChrome拡張機能です。予期しない音声の再生を防ぎ、静かなブラウジング体験を提供します。

## 機能

- **自動ミュート**: 新しく開かれるタブは自動的にミュート状態になります
- **簡単な切り替え**: 拡張機能のアイコンをクリックするだけで、タブのミュート状態を切り替えられます
- **視覚的フィードバック**: タブのミュート状態に応じてアイコンが変化します
- **軽量**: 最小限のリソースで動作します
- **多言語対応**: 英語と日本語をサポートしています

## インストール方法

### Chrome ウェブストアからインストール（推奨）

1. [Chrome ウェブストア](https://chromewebstore.google.com/detail/%E9%9D%99%E5%AF%82/gaomeihjahnankimbcfcpgadfoldhebk?authuser=0&hl=ja)にアクセスします
2. 「Chromeに追加」ボタンをクリックします
3. 確認ダイアログで「拡張機能を追加」をクリックします

### 開発者モードでインストール

1. このリポジトリをクローンまたはダウンロードします
2. Chromeで `chrome://extensions/` にアクセスします
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします
5. ダウンロードしたリポジトリの `src` フォルダを選択します

## 使用方法

1. インストール後、新しく開くタブは自動的にミュート状態になります
2. タブのミュート状態を切り替えるには、拡張機能のアイコンをクリックします
   - ミュート状態: ![ミュートアイコン](etc/muted256.png)
   - アンミュート状態: ![アンミュートアイコン](etc/unmuted256.png)
3. シークレットモードで使用するには、拡張機能の設定で「シークレットモードでの実行を許可する」をオンにしてください

## 開発者向け情報

### プロジェクト構造

```text
src/
├── manifest.json        # 拡張機能の設定ファイル
├── service_worker.js    # バックグラウンドスクリプト
├── _locales/            # 多言語サポート
│   ├── en/              # 英語
│   │   └── messages.json
│   └── ja/              # 日本語
│       └── messages.json
└── images/              # アイコン画像
    ├── muted*.png       # ミュート状態のアイコン
    └── unmuted*.png     # アンミュート状態のアイコン
```

### 開発環境のセットアップ

1. 依存パッケージのインストール:

   ```bash
   npm install
   ```

2. コードの検証:

   ```bash
   npm run lint
   ```
