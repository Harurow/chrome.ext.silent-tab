# ADR-0001 アンミュートしたタブを自前で記録せず、`mutedInfo.reason` で判定する

| | |
| --- | --- |
| 状態 | 採択（2026-08-22）。**1.1.1 で実装**（コミット 2e382c0） |
| 対象 | FR-05, NFR-01, CON-03 |
| 仕様 | [SPEC-SW-02](../specs/service-worker.md) |
| 発端 | 1.1.0 は「アンミュートしたタブの ID」を `chrome.storage.session` に記録していた。そのために `storage` 権限を宣言していた |

---

## 決定

**記録をやめ、タブの `mutedInfo.reason` の有無で「利用者がアンミュートしたか」を判定する。**

`reason` は「最後にミュート状態を変えた理由」で、一度も変えていないタブには無い。
この拡張機能は自分からアンミュートしないので、「アンミュートで `reason` あり」は誰かが意図してアンミュートしたことを意味する。
アイコンでのアンミュート（`'extension'`）とタブのスピーカーでのアンミュート（`'user'`）を区別する必要は無い。

| 案 | 判定 |
| --- | --- |
| **(a) 採用** `mutedInfo.reason` を読む | Chrome が同じ情報をタブごとに持っている。権限が要らず、タブを閉じれば情報も消える |
| (b) `chrome.storage.session` に記録する（1.1.0） | 却下。`storage` 権限が要る（NFR-01）。読み書きの順序制御、タブを閉じたときの破棄、`onReplaced` でのタブ ID の引き継ぎが要り、`service_worker.js` は 263 行あった（(a) で 184 行） |
| (c) Service Worker のメモリに持つ | 却下。Service Worker が止まると消える（CON-01）。止まるたびに利用者のアンミュートが消える |

## 代償

- ブラウザを再起動したとき、復元したタブが前回の `reason` を持っている可能性がある（未実測）。起動時は `reason` を無視して強制する（SPEC-SW-03）
- 拡張機能の更新・無効化で Chrome が付ける `reason: 'extension'` を、利用者のアンミュートと区別できない（CON-04）。これが ADR-0002 / ADR-0003 につながった
