# 背景・目的・スコープ

## 背景

タブを開いた瞬間に、動画や広告の音声が鳴り出すことがある。
どのタブが鳴っているかを探して止めるまで、音は流れ続ける。

## 目的

**タブを常にミュートした状態に保ち、予期しない音声の再生を防ぐ。**

- 音を聞きたいタブだけを、利用者が自分でアンミュートする（既定はミュート）
- 利用者がアンミュートしたタブは、利用者の判断として尊重する

## 利用者

| | |
| --- | --- |
| 想定利用者 | Chrome を使う人全般 |
| 技術レベル | Chrome 拡張機能をインストールできる程度 |
| 規模 | 個人開発・Chrome ウェブストアで一般公開（1.0.0 は 2022-06） |

## スコープ

### 対象

- すべてのタブの自動ミュート（新しいタブ・ページの遷移・ブラウザの起動時など）
- ツールバーのアイコンによる、タブごとのミュートの切り替え
- ツールバーのアイコンによる、タブのミュート状態の表示
- 英語と日本語の表示

### 対象外

- 音量の調整、音声が鳴っているかの検出
- ドメインごとの例外・オプションページ・キーボードショートカット（要望はあるが未着手。FR-09〜11）
- Chrome 以外のブラウザでの動作確認

## 前提

- Chrome のタブのミュート機能（タブ単位の消音）を使う。音声そのものには触れない
- シークレットウィンドウで動かすかは、利用者が Chrome の拡張機能の設定で決める（拡張機能側では何もしない）

## 用語

| 用語 | 意味 |
| --- | --- |
| ミュート / アンミュート | Chrome のタブ単位の消音 / その解除 |
| アイコン | ツールバーに出る、この拡張機能のボタン |
| タブのスピーカー | タブの見出しに出る、Chrome 自身のミュート切り替え |
| 更新 | 拡張機能の新しい版の適用。`chrome://extensions` の再読み込みも同じ扱いになる |
| 再有効化 | `chrome://extensions` で拡張機能を無効にしてから有効に戻すこと |
