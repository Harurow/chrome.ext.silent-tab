# 非機能要件

## NFR-01 権限を要求しない

インストール時・更新時に、権限の確認を求めないこと。そのために、権限を一切宣言しないこと。

**製品の売り。** 実装の都合で権限を足す前に、別の手段を探す（CON-03 / ADR-0001 / ADR-0003）。

| | |
| --- | --- |
| 優先度 | 必須 |
| 状態 | ✅（1.1.1 で `storage` を外し、宣言ゼロに戻した） |
| 仕様 | SPEC-MF-03 |

---

## NFR-02 利用者の情報を収集・送信しない

- 閲覧履歴・タブの URL・題名を読まないこと
- 拡張機能自身が外部へ通信しないこと

| | |
| --- | --- |
| 優先度 | 必須 |
| 状態 | ✅ 通信するコードが無く、URL・題名は権限が無いので読めない（NFR-01） |
| 仕様 | SPEC-MF-03, SPEC-SW-01 |

---

## NFR-03 Service Worker が停止・再起動しても振る舞いが変わらない

Chrome は使われていない拡張機能の処理（Service Worker）を止め、次のイベントで起こし直す（CON-01）。
止まって起き直す前と後で、どのタブがミュートかが変わらないこと。

| | |
| --- | --- |
| 優先度 | 必須 |
| 状態 | ✅ |
| 仕様 | SPEC-SW-04 |
