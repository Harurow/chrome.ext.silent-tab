## 書き方

- 1判断1ファイル。`NNNN-<英小文字ハイフン>.md`
- **選ばなかった案とその理由を必ず書く。** 採用案だけ書くと後で再検討できない
- 決まった内容そのものは `docs/notes/specs/` に書く。ADR には「なぜそれにしたか」だけを書く
- 覆した場合はファイルを消さず、状態を「置き換え（→ NNNN）」に変える
- 版は `src/manifest.json` と `package.json` にある版だけを書く。作業の途中経過を版として書かない
