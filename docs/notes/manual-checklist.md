# 手動確認チェックリスト

自動テストで守れない範囲を人の手で確かめるためのリスト。
**自動テスト（`npm test`）で見ているものはここに書かない**（二重に持たない）。一覧は [TEST-CATALOG.md](../TEST-CATALOG.md)。

- **所要時間の目安:** 全項目で 5 分
- **やり方:** `chrome://extensions/` で `src/` を読み込むか、ストアから入れた版で、各項目の「操作」を行い、「期待結果」どおりなら `[x]` にする

## 変更箇所 → 実施する項目

| 変更したもの | 実施する項目 |
| --- | --- |
| `muteTab` / `onCreated` / `onUpdated` / `onClicked` / `syncAllTabs*` | M-1, M-2 |
| `updateTabIcon` / `actionIcons` / `onUpdated` / `src/images/` / manifest のアイコン | M-3 |
| `src/_locales/` / manifest の `name`・`description` | M-4 |
| manifest のそれ以外 | M-1〜M-4 すべて |
| `src/` を触っていない変更（`scripts/`・`tests/`・文書だけ） | 不要 |
