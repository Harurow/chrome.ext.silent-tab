# プロジェクト概要: Chrome拡張機能「静寂（Silent Tab）」

## 目的
「静寂（Silent Tab）」は、Chromeブラウザで新しいタブを開く際に、自動的にミュート状態で開くことを保証するChrome拡張機能です。これにより、予期しない音声の再生を防ぎ、ユーザーに静かなブラウジング体験を提供します。

## 主要機能
1. 新しく開かれるタブを自動的にミュート状態にする
2. 拡張機能のアイコンをクリックすることで、現在のタブのミュート状態を切り替える
3. タブのミュート状態に応じてアイコンを変更する（ミュート/アンミュート）

## 技術スタック
- Chrome Extension API (Manifest V3)
- JavaScript
- HTML/CSS（最小限）

## 対象ユーザー
- 複数のタブを同時に開くことが多いユーザー
- 予期しない音声再生に悩まされているユーザー
- 静かな環境（オフィス、図書館など）でブラウジングするユーザー

## 開発目標
1. シンプルで直感的なユーザーインターフェース
2. 高いパフォーマンスと低リソース消費
3. 安定した動作と信頼性
4. 多言語対応（現在は英語と日本語）

## 将来の展望

- ショートカットキーのサポート
- より詳細な音声管理機能
